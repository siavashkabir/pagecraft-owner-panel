# Pagecraft Owner Panel

الان می‌خوام این سایت رو گسترش بدم و از حالت تک‌صفه‌ای دربیارم؛ فایل HTML قبلی (index.html) پیوست است. طراحی بازطراحی باشد: طرح خیلی حرفه‌ای و کامل، همچنین پنل ادیت داخل سایت برای من که مالک سایت هستم. (پاسخ انتخابی شما به سوال صفحات: «طرح خیلی حرفه‌ای و کامل، همچنین پنل ادیت داخل سایت برای من که مالک هستم»؛ طراحی: بازطراحی). لوگوهای نهایی ساخته‌شده در پیوست‌ها هستند. در انتها یک اسکرین‌شات از صفحه اصلی و پنل مدیریت بگیر.
